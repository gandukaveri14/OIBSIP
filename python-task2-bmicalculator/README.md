
# BMI Calculator

## Project Overview
This project is a simple BMI (Body Mass Index) Calculator
developed using Python. It calculates BMI based on a
person's weight in kilograms and height in metres.

## Features
- Accepts weight in kilograms
- Accepts height in metres
- Calculates BMI using the BMI formula
- Displays BMI rounded to two decimal places
- Classifies the BMI result
- Handles invalid numeric input
- Rejects zero and negative values

## Technologies Used
- Python 3
- Visual Studio Code

## Formula
BMI = Weight (kg) / (Height (m) * Height (m))

## BMI Categories
- Below 18.5: Underweight
- 18.5 to below 25: Normal weight
- 25 to below 30: Overweight
- 30 and above: Obese

## How to Run
1. Install Python 3.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

   python bmi_calculator.py

## Sample Output
Your BMI: 20.76
Category: Normal weight

## Error Handling
The program handles invalid text input and rejects
zero or negative weight and height values.

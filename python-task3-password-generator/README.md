
# Random Password Generator

## Project Overview
A Python program that generates random passwords
based on the length selected by the user.

## Features
- Password length from 8 to 64 characters
- Uppercase and lowercase letters
- Numbers and special symbols
- Secure random selection using Python secrets
- Input validation and error handling

## Technologies
- Python 3
- string module
- secrets module

## How to Run
1. Open the project folder in VS Code.
2. Open the terminal.
3. Run: python password_generator.py
4. Enter a password length between 8 and 64.

## Testing
Test valid lengths, lengths outside the allowed
range, and non-numeric input.

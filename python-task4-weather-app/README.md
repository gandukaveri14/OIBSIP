# Basic Weather App

## Project Description
A simple Python application that retrieves real-time weather information for a city using the OpenWeatherMap API.

## Features
- Search weather by city name
- Display temperature in Celsius
- Display humidity percentage
- Display weather conditions
- Handle invalid city names and API errors

## Technologies Used
- Python
- Requests library
- OpenWeatherMap API

## Requirements
Install the required library:

```bash
pip install requests
```

## How to Run
1. Configure your OpenWeatherMap API key securely.
2. Open the terminal in the project folder.
3. Run:

```bash
python weather_app.py
```

4. Enter a city name when prompted.

## Example Output

```text
===== WEATHER REPORT =====
City: Chennai
Temperature: 29.92 °C
Humidity: 86%
Condition: Scattered Clouds
```

## Security
Keep your API key private. Do not upload it to a public repository.
